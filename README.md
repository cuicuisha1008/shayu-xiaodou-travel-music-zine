# 鲨鱼小豆 · 旅行声像 ZINE

由 **鲨鱼小豆** 创作与维护的旅行照片 × 音乐意象海报 Skill。

把旅行、街头、建筑、风景或人物照片，转化为带有音乐隐喻的中文 ZINE 海报。

它不会先套用一张唱片、耳机或磁带模板，而是先阅读照片中的人物关系、空间结构、光线、颜色、重复形状与情绪，再从原图里抽取一个真正成立的音乐物件和一句中文命题。

## 它会做什么

- 从照片中提炼一个音乐意象，例如声道、采样器、磁带、CD、唱片、录音机、波形或信号路径。
- 给出 3 版同一意象下的中文文案，并推荐其中一版。
- 询问是否有指定歌曲；没有时，从内置的 100 首氛围曲中自动匹配。
- 先展示音乐物件底图，确认方向后再完成原片回填、排版与检查。
- 输出 3:5 小红书海报快速预览；确认后可选导出 4K 终稿。

## 内置歌曲范围

内置曲库包含 100 首已补齐时长的氛围曲，主要覆盖：

- R&B、Soul、Jazz、Indie、Pop、轻电子与复古听感；
- 海岸与水边、雨天、城市街灯、夜行、森林、公路、室内和落日；
- 松弛、浪漫、明亮、温柔、孤独、回望与梦感；
- 英语及混合语种为主，也包含少量韩语等曲目。

如果用户提供明确的“歌名 + 歌手”，Skill 会直接使用指定歌曲，并跳过整份内置歌单，节省时间与上下文。

## 使用流程

1. 上传一张高清原图。
2. Skill 分析照片，确定音乐意象，提供 3 版文案，并询问歌曲。
3. 文案与歌曲确认后，生成并展示音乐物件底图。
4. 回复“继续生成最终预览”，得到完整的 1080×1800 预览大图。
5. 画面确认后，可选导出 3840×6400、300 DPI 的 4K 终稿。

示例请求：

```text
使用 $travel-music-zine，把这张旅行照片做成音乐 × 旅行的中文 ZINE 海报。
```

## 模型与时间建议

- **5.6 Sol（推荐）**：意象理解、构图判断与材质表现最好。完整快速预览通常约 12–30 分钟，不含用户确认与返工等待。
- **5.6 Terra**：速度更快，通常可达到约 70%–80% 的效果。完整快速预览通常约 8–20 分钟。
- **Luna（不推荐）**：实测在意象抽取、音乐物件构造和质感上明显较弱，返工可能抵消节省的时间。

实际时间会受图片复杂度、图像生成队列和修改次数影响。

## 原片保真

- 顶部照片只允许 EXIF 方向校正、等比裁剪、缩放、RGB 转换与高质量重采样。
- 不重绘人物，不改变五官、姿势、比例、物体数量、透视、文字或光线关系。
- 不给原片叠加水波纹、纸纹、压花、网点、颗粒或统一滤镜。
- 最终排版会以原始照片像素重新回填，不沿用生成底图中的照片区域。

## 图片要求与隐私

- 默认要求原图短边至少 1000 px。
- 如果收到的是相册缓存的低清缩略图，Skill 会先停止生成，并引导用户从“照片”App 导出 HEIC/JPG 后重新上传。
- 只检查用户本次明确提供的文件，不扫描照片图库、父目录、iCloud 或其他无关文件。

## 固定输出规格

- 工作母版：2160×3600 PNG，3:5。
- 快速预览：1080×1800 PNG。
- 可选 4K：3840×6400 PNG，300 DPI。
- 使用固定母版控制照片框、分隔线、文字层级、播放器和音乐物件的几何关系。

在 Codex 中发送：
